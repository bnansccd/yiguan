1.1 项目背景

中医理疗馆在日常运营中面临以下痛点：

- 客户档案纸质管理，信息分散不易查询
- 预约排班依赖手工登记，容易冲突遗漏
- 划价收费手工计算，易出错且对账困难
- 药品耗材库存管理粗放，断货或过期风险高
- 经营数据难以统计，缺乏决策依据

为解决上述问题，需建设一套**单机部署**的业务管理系统，覆盖日常经营全流程，实现管理规范化、数据可追溯、运营提效率。

### 1.2 项目目标

本系统定位于**单机环境运行**，满足中医理疗馆日常业务管理需求，实现：

| 目标领域 | 具体目标 |
| --- | --- |
| 客户管理 | 客户档案电子化，健康记录可追溯，消费轨迹清晰 |
| 业务闭环 | 预约→挂号→接诊→划价收费→理疗执行→离店全流程线上化 |
| 财务管理 | 收费结算准确，预充值账户精细管理，日结对账高效 |
| 库存管理 | 药品耗材进销存可控，预警及时 |
| 经营决策 | 自动生成多维度经营报表，辅助经营决策 |

### 1.3 适用范围

本PRD适用于系统设计、开发、测试、验收全流程管理，面向产品经理、开发工程师、测试工程师、项目实施人员及项目干系人。

### 1.4 术语与缩写

| 术语  | 定义  |
| --- | --- |
| 理疗项目 | 中医理疗馆提供的服务项目，如推拿、艾灸、拔罐、刮痧、针灸、正骨等 |
| 处方  | 医生开具的治疗方案，可包含理疗项目组合和/或中药饮片处方 |
| 划价  | 根据处方或项目明细逐项计算应收费用的过程 |
| 建档  | 为客户建立首诊电子健康档案，记录基本信息和健康数据 |
| 预充值 | 客户提前向账户存入资金，后续消费时直接从余额扣除 |
| 扣次  | 针对疗程类项目，按次数而非金额进行消费扣减（如10次卡） |
| 年卡  | 一种会员权益卡，客户一次性购买后可在有效期内按次享受指定理疗项目，收费时自动抵扣对应次数 |
| 挂号  | 客户到诊后在系统登记，分配接诊医生/理疗师 |
| 门诊病历 | 单次诊疗的完整记录，含主诉、诊断、治疗方案等 |
| 盘盈/盘亏 | 库存盘点时，实盘数量与账面数量的差额（多则为盈，少则为亏） |
| 九种体质 | 中医体质学说中的九种体质类型：平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质 |

## 2. 系统总体要求

### 2.1 运行环境

| 项目  | 要求  |
| --- | --- |
| 部署方式 | 单机部署，无需联网运行，数据本地存储 |
| 操作系统 | Windows 10/11 及以上，兼容 Windows Server 2016+ |
| 数据库 | SQLite（嵌入式，零配置，单文件存储） |
| 终端设备 | PC电脑，分辨率建议 1920×1080 及以上 |
| 外设支持 | 支持小票打印机（58mm/80mm）、普通A4打印机 |
| 运行时依赖 | 无需互联网；本地运行，不接入云端服务 |

### 2.2 用户角色定义

| 角色  | 主要职责 | 典型使用者 |
| --- | --- | --- |
| 管理员 | 系统参数设置、数据备份恢复、员工账号管理、权限分配 | 老板/店长 |
| 前台  | 客户建档、预约登记、挂号分诊、收费结算、充值操作 | 前台接待 |
| 理疗师 | 接诊记录、病历书写、处方开立、治疗执行登记 | 理疗师/医师 |
| 库管  | 药品耗材入库、盘点、库存查询（可独立角色或由前台兼任） | 库管员 |
